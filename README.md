# WATERLINE

수면 위와 아래가 이어진 도시의 가장자리에서 두 아이와 거대한 변이동물의 하루를 살아가는 생활형 사건 게임 프로토타입.

## 실행

```bash
npm start
```

Railway에서는 GitHub 저장소 루트에 `package.json`, `server.js`, `railway.toml`, `public/`가 바로 보이도록 올리고 Start Command는 `npm start`를 사용합니다.

## 이번 버전

- 매일 바뀌는 행동 후보
- 캐릭터 간 능동적 상호작용
- 장소별 활동과 사건
- 숨겨진 결과와 주사위 위험 판정
- 큰 결과 카드
- 일일 목표
- 장기 사건과 후속 사건
- 모바일 레이아웃
- 브라우저 자동 저장

## 모바일

iOS Safari / Android Chrome을 기준으로 한 반응형 레이아웃입니다. 서버가 정상적으로 배포되어 있다면 휴대폰 브라우저에서 Railway URL로 접속해 플레이할 수 있습니다.
