# WATERLINE V86

Node.js 기본 HTTP 서버로 실행되는 단일 플레이어 웹 프로토타입입니다.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:3101` 접속.

## V86 주요 기능

- A / B / 거대동물 중심의 생활 시뮬레이션
- 장소별 전용 사건과 이야기 이벤트
- 일부 사건의 숨은 위험 판정: D6 + 성향 보정
- 선택 결과는 주사위를 굴린 뒤 공개
- 시장/선착장/구주거구/기록관/역/저택별 전용 행동
- 캐릭터 성향과 관계에 따른 케미 장면
- 장기 사건과 미해결 사건 큐
- DAY 무제한 진행
- localStorage 자동 저장
